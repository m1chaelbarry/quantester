# Opt-in Carver vol-target live sizer

D5 keeps Kelly, Vince \(f^*\), and vol-target as research libraries; live sizing defaults to cash-base percent. EWMAC + crypto carry needs Carver’s \(N \propto F/(\sigma \cdot 10)\) and an Inertia Buffer in the event loop, so those become an **opt-in** `PortfolioManager` sizer. The default sizer does not change. Combined Forecast stays on the strategy; quantity stays in the portfolio. Fractional Kelly is not layered on vol-target (that would double-leverage). Live size is vol-target + Inertia Buffer + Drawdown De-lever only; Kelly stays the research library (`sizing.py`) and may appear as a post-trade diagnostic, not as a second scale. This strategy uses Drawdown De-lever on target vol; it does not wire `DailyDrawdownBreaker`. Numeric hyperparameters (EWMAC spans, target vol, inertia β, DLR thresholds, DVOL cut) are **research defaults from the architecture report, not product locks** — they are to be discovered by backtest/study, not frozen in the ADR.

**Considered options.** Strategy-computed \(N_{\text{pos}}\) (violates the strategy contract). Direction-only `PercentEquitySizer` (does not implement this strategy).
